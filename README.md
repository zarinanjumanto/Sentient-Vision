# Sentient-Vision
Facial Recognition And Emotion  Detection


📌 Project Description

This project focuses on Facial Recognition and Emotion Detection using computer vision and artificial intelligence. The system aims to identify human faces and detect facial expressions to recognise emotions such as happiness, sadness, anger, surprise, and neutrality.

The project demonstrates how AI can be used to analyse facial features and expressions for educational and research purposes.

🎯 Project Objectives

- To explore facial recognition technology.
- To detect and analyse human facial expressions.
- To understand the role of artificial intelligence and computer vision.
- To develop a simple system for emotion detection.
- To learn teamwork and collaborative software development using GitHub.

🛠️ Technologies

- Python
- OpenCV
- Computer Vision
- Artificial Intelligence
- GitHub

🚀 Expected Outcome

The expected outcome is a system that can detect faces from images or a live camera feed and classify visible facial expressions into different emotion categories.
